## Included pages
Login, Home, Dashboard, Tasks, Add Task, Members, Reports, Notifications and Settings.

## Functions
Login/session handling, logout, responsive navigation, dark mode, task creation, task deletion,
task progress/status/assignee updates, task comments, search/filter, task categories, member summaries,
dashboard counts/charts, reports and CSV export.

## Run
Open `index.html` directly, or serve the folder with any static HTTP server.

## Deploy
The folder can be uploaded to Netlify, Vercel, GitHub Pages, Azure Static Web Apps, cPanel or any static host.

## Important production note
This package is a complete static front-end and persists demo data with browser `localStorage`.
For a real multi-user production deployment where data is shared across devices, replace localStorage/auth
with a server-side API, database and secure password authentication. Never use the demo credentials as
production security.
