## Team Reflection

Our team developed PMS (Project Management Syncboard), a collaborative project management system for managing tasks, members, progress updates, notifications and communication.

The project work was divided according to individual responsibilities. Backend members worked on server connections, authentication and data handling. Frontend members developed the user interfaces and connected them with the system functionality. The task and settings developer worked on task progress, task management and configuration features. The admin and member interface developer created the separate user experiences for administrators and members. Testing responsibilities focused on checking buttons, forms, navigation, responsiveness and fixing errors.

One of the main challenges was integrating all system components while maintaining consistent data between the frontend, backend and database. The team solved this through communication, shared development responsibilities and continuous testing.

This project improved our knowledge of full-stack development, REST APIs, authentication, database connections, responsive design, task management and teamwork. In the future, we would improve the system by adding more end-to-end tests, advanced analytics, richer member profiles and additional project management features.

Overall, the team successfully combined individual contributions to create a functional and collaborative PMS application.
